# 🛰️ SCOUT – Axion

Sistema de coleta, análise e visualização de dados para competições da FIRST Robotics Competition (FRC).

O Scout foi desenvolvido para transformar dados brutos de partidas em informações estratégicas, permitindo decisões rápidas e inteligentes durante torneios.

---

## 🎯 Objetivo

Criar uma plataforma moderna e eficiente para:

- 📊 Coletar dados em tempo real das partidas  
- 📈 Gerar estatísticas automáticas  
- 🧠 Calcular métricas estratégicas (consistência, eficiência, ranking interno)  
- 🤝 Auxiliar na definição de alianças  
- 🏆 Aumentar a performance competitiva da equipe

---

## 🚀 Principais Funcionalidades

- Sistema de login para scouts  
- Cadastro de partidas por grupos de trabalho  
- Tabelas dinâmicas de ranking  
- Cálculo automático de:
  - Média de pontuação
  - Consistência
  - Ranking de melhores escolhas
- Gráficos interativos
- Interface responsiva
- Filtros dinâmicos por equipe ou partida

---

## 🛠️ Tecnologias Utilizadas

- React  
- Vite  
- TailwindCSS  
- Chart.js  
- JavaScript (ES6+)  
- Spring Boot
- MySQL 

---

## 🧮 Lógica Estratégica

O sistema utiliza algoritmos próprios para gerar métricas, das quais permitem identificar:

- Times estáveis  
- Times explosivos  
- Times arriscados  
- Possíveis escolhas de aliança  

---

## 🧠 Filosofia do Projeto

O Scout não é apenas um sistema de coleta de dados.  
Ele é uma ferramenta estratégica construída para:

> Transformar informação em vantagem competitiva.

Nosso foco é unir:

- Engenharia  
- Estatística  
- Estratégia de jogo  
- Experiência de usuário
